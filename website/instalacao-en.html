Installation

The security warnings below are expected: they do not mean a defect or a virus and only appear the first time. The app does not carry Microsoft's or Apple's paid signature. Maestruc does not install the instruments: each one is installed from its own site.

Windows

  1. Download maestruc-0.1.0-windows-x64.exe and open it.
  2. Windows shows “Windows protected your PC”: click “More info”, then “Run anyway”. If asked for administrator permission, click “Yes”.
  3. Click “Next” to the end. Maestruc is then in the Start menu.
  4. Without installing: unzip the .zip and open Maestruc.exe.

macOS (Intel and Apple Silicon, 10.15 or newer)

  1. Download maestruc-0.1.0-macos-universal.dmg, open it and drag Maestruc into Applications.
  2. On first launch macOS blocks the app (“Apple could not verify…”). Click “OK” or “Done”, not “Move to Trash”.
  3. Allow it once: System Settings → Privacy & Security → “Open Anyway”. On macOS 14 or earlier: right-click the app → “Open” → “Open”.
  4. If the button does not appear, run this in Terminal (no output = it worked):
xattr -dr com.apple.quarantine "/Applications/Maestruc.app"

Linux (x86-64, glibc 2.35 or newer)

  • Ubuntu, Debian and Mint: double-click the .deb, or sudo apt install ./maestruc-0.1.0-linux-x86_64.deb.
  • Other distributions: the AppImage (make it executable and open it) or the .tar.gz (unpack it and run ./install.sh, which installs into ~/.local, no root).
  • Launch tested on Debian 12, Ubuntu 24.04, Fedora and Arch.
  • With PipeWire (pipewire-jack), Maestruc uses the system's audio server; without it, the sound card through the app itself.

Where things live

  • Recordings: Music/RASGO/Maestruc/recordings/, one folder per day and one per take. The … button picks another folder.
  • Settings, your own catalogue (catalog.json) and logs: RASGO/Maestruc in the system's data folder (~/.config on Linux, %APPDATA% on Windows, ~/Library/Application Support on macOS).
  • Installing, upgrading or uninstalling never deletes any of this. It is the same layout in every instrument of the family.

Windows and macOS are built and tested in continuous integration but have not yet been opened on real machines. If something does not open, write to the contact below with your system version and the message shown.
