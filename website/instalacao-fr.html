Installation

Les avertissements de sécurité ci-dessous sont attendus : ils ne signalent ni défaut ni virus et n'apparaissent que la première fois. L'app ne porte pas la signature payante de Microsoft ni d'Apple. Maestruc n'installe pas les instruments : chacun s'installe depuis son propre site.

Windows

  1. Téléchargez maestruc-0.1.0-windows-x64.exe et ouvrez-le.
  2. Windows affiche « Windows a protégé votre ordinateur » : cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». S'il demande l'autorisation d'administrateur, cliquez sur « Oui ».
  3. Cliquez sur « Suivant » jusqu'au bout. Maestruc est alors dans le menu Démarrer.
  4. Sans installer : décompressez le .zip et ouvrez Maestruc.exe.

macOS (Intel et Apple Silicon, 10.15 ou plus récent)

  1. Téléchargez maestruc-0.1.0-macos-universal.dmg, ouvrez-le et glissez Maestruc dans Applications.
  2. À la première ouverture, macOS bloque l'app (« Apple n'a pas pu confirmer… »). Cliquez sur « OK » ou « Terminé », pas sur « Placer dans la corbeille ».
  3. Autorisez-la une fois : Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ». Sous macOS 14 ou antérieur : clic droit sur l'app → « Ouvrir » → « Ouvrir ».
  4. Si le bouton n'apparaît pas, lancez ceci dans le Terminal (aucune réponse = réussi) :
xattr -dr com.apple.quarantine "/Applications/Maestruc.app"

Linux (x86-64, glibc 2.35 ou plus récente)

  • Ubuntu, Debian et Mint : double-cliquez sur le .deb, ou sudo apt install ./maestruc-0.1.0-linux-x86_64.deb.
  • Autres distributions : l'AppImage (rendez-la exécutable et ouvrez-la) ou le .tar.gz (décompressez-le et lancez ./install.sh, qui installe dans ~/.local, sans root).
  • Ouverture testée sous Debian 12, Ubuntu 24.04, Fedora et Arch.
  • Avec PipeWire (pipewire-jack), Maestruc utilise le serveur audio du système ; sans lui, la carte son par l'app elle-même.

Où sont les choses

  • Enregistrements : Musique/RASGO/Maestruc/recordings/, un dossier par jour et un par prise. Le bouton … choisit un autre dossier.
  • Préférences, catalogue personnel (catalog.json) et journaux : RASGO/Maestruc dans le dossier de données du système (~/.config sous Linux, %APPDATA% sous Windows, ~/Library/Application Support sous macOS).
  • Installer, mettre à jour ou désinstaller n'efface rien de tout cela. C'est la même organisation dans tous les instruments de la famille.

Windows et macOS sont compilés et testés par l'intégration continue mais n'ont pas encore été ouverts sur de vraies machines. Si quelque chose ne s'ouvre pas, écrivez au contact ci-dessous avec la version du système et le message affiché.
